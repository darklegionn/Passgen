# 🔐 Password Generator

A simple and customizable **Python-based Password Generator** designed to help users create strong and varied password combinations for educational, testing, and personal security purposes.

---

## 📌 About This Tool

The **Password Generator** was created as a learning project to understand how passwords can be generated programmatically using Python.

The tool can generate password combinations using:

* 🔢 Numbers
* 🔣 Special characters
* 🔤 Different character combinations
* 🔀 Different arrangements of user-provided characters
* 🎲 Randomly generated combinations
* ⚙️ Custom password-generation options

The main purpose of this project is to learn Python programming, string manipulation, randomization, file handling, and basic concepts related to password security.

---

# ✨ Features

* Generate passwords using numbers and symbols.
* Create different combinations from a reference password.
* Generate randomized password combinations.
* Customize the characters used for generation.
* Simple command-line interface.
* Works on Linux and Windows.
* Open-source and easy to modify for learning.

# 🐧 Installation on Linux

### Prerequisites

Make sure Python 3 is installed.

Check your Python version:

```bash
python3 --version
```

If Python is not installed, install it using your distribution's package manager.

### Option 1 — Clone from GitHub

1. Open the terminal.

2. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/PasswordGenerator.git
```

3. Enter the project directory:

```bash
cd PasswordGenerator
```

4. Run the program:

```bash
python3 password_generator.py
```

---

### Option 2 — Download the Python file

If you don't want to clone the entire repository:

1. Download `password_generator.py` from the GitHub repository.
2. Open the terminal.
3. Navigate to the directory containing the file:

```bash
cd ~/Downloads
```

4. Run:

```bash
python3 password_generator.py
```

# 🪟 Installation on Windows

### Prerequisites

Install **Python 3** on your Windows computer.

Check whether Python is already installed:

```powershell
python --version
```

or:

```powershell
py --version
```

### Steps

1. Open **PowerShell** or **Command Prompt**.

2. Clone the repository:

```powershell
git clone https://github.com/YOUR_USERNAME/PasswordGenerator.git
```

3. Enter the project directory:

```powershell
cd PasswordGenerator
```

4. Run the program:

```powershell
python password_generator.py
```

If `python` doesn't work, try:

```powershell
py password_generator.py
```

# 🚀 How to Use

After starting the program:

```bash
python3 password_generator.py
```

follow the instructions displayed in the terminal.

Depending on the available options, you can provide a reference password or characters and generate different combinations.

### Example

Suppose the reference password is:

```text
98765123@#@
```

The tool can experiment with different arrangements such as:

```text
@#@98765123
@#@123456789
1234@1234
1234#1234
```

The purpose is to demonstrate how different character arrangements can be generated programmatically.

> **Important:** The exact output depends on the version and configuration of the tool.
